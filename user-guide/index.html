User Guide

Create a local vault, save a login, and know which steps require your organization administrator.

Local vault data stays encrypted in the extension. Organization sync is optional and requires OIDC setup.

Create a vault

  1. Open the EPV extension and choose Create local vault.
  2. Set a strong vault passphrase and store it somewhere safe. This passphrase unlocks the local vault; it is not your organization password.
  3. Keep your recovery code if the extension offers recovery enrollment. EPV cannot recover a user-held recovery code that has been lost.
No default credentials

EPV does not ship with a shared username or password. You create the local vault passphrase on first use.

Unlock and lock

Unlock the vault with its passphrase when you need to use saved items. Select Lock when you finish. The extension also applies its configured idle-lock behavior; after a browser restart, expect to unlock again.

Sign-in and vault unlock are separate: signing in to an organization authorizes server access, while unlocking releases the local ability to decrypt your vault.

Create your first login

  1. In the extension side panel, choose + New item and select Login.
  2. Enter a descriptive name, username, password, and the website origin if you want matching suggestions.
  3. Use Generate to create a password that follows the current effective policy shown by the extension.
  4. Choose Save encrypted item. The login content is encrypted in the browser before it is stored.

For your first local entry, use a non-production test credential. Do not store organization secrets in an unqualified local development deployment.

Generate and check a password

The generator uses the extension's effective password requirements. If you run the optional breach check, EPV sends only a short SHA-1 prefix to the Have I Been Pwned Pwned Passwords service; the password and remaining hash stay on your device.

Site-specific password rotation is not automatic. If a policy reports an old or non-compliant password, change it at the destination website and update the saved login.

Use a login on a website

EPV offers user-initiated suggestions for an exact secure website origin. Confirm the match and choose the login in the extension. The extension does not submit the website form for you.

Destination websites can read filled values

Once a password is entered into a site's form, that site can access it. EPV does not promise confidentiality from the destination website.

Connect your organization

Organization sync is disabled until an administrator configures the API and extension with the same OIDC issuer and audience, allows the extension origin, and provisions your membership. The extension's Connect organization control stays unavailable until it is configured.

After sign-in, select your organization and choose Sync now. Local vault creation and unlock continue to work without this connection.
