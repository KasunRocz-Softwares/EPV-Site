FIRST RUN

From install to first login

For local use, start in the extension. Your vault passphrase unlocks your encrypted records; it is separate from any organization account.

  1. 01
    Load EPV in your browser

    Use the unpacked build for development or a signed release archive.

  2. 02
    Create your local vault

    Choose a passphrase you can keep safe. No default login is supplied.

  3. 03
    Save a login entry

    Add its name, username, password, and optional website in the side panel.

Need team sync or the admin console?

An administrator must configure an OIDC identity provider, build settings, and your organization membership first.
