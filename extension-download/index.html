Extension Download

Build the extension from source and load it unpacked. Signed release archives are supported once a version is published.

No default sign-in is included. Organization login requires OIDC configuration.

Build from source

From the EPV repository root, run:

Repository root
pnpm install --frozen-lockfile
pnpm --filter @epv/extension build

The unpacked extension is generated at apps/extension/.output/chrome-mv3. For organization sync, set the public extension OIDC/API configuration before building; local vault creation does not require those settings.

Load the extension in Brave or Chrome

  1. Open brave://extensions or chrome://extensions.
  2. Turn on Developer mode.
  3. Select Load unpacked.
  4. Select the local build folder apps/extension/.output/chrome-mv3, or an extracted release directory containing manifest.json.
  5. Open the EPV side panel, create a local vault, and add a test login.

In Edge, open edge://extensions and follow the same Load unpacked steps. Browser names and menu labels can change between releases.

Use a signed release

No public release has been published yet

Until one is, use the build steps above. This page does not imply that a production release is available.

When a version is published to the project's GitHub Releases, download its epv-<version>-extension-chrome.zip asset and extract it to a stable folder before loading it as shown above.

Verify a release

Download the matching SHA256SUMS and Sigstore bundle attached to the same GitHub release. Compare the ZIP digest and verify the bundle using the official Sigstore instructions before installing the extension.

Install only a release whose provenance you trust. Do not load an extension from an unknown archive or third-party mirror.

Organization sign-in

The extension authenticates through your organization's OIDC provider. The provider must register the extension as a public client with Authorization Code + PKCE and allow the exact browser redirect URI. The API issuer/audience, extension build settings, and organization membership must also match.

If Connect organization is disabled, use the local vault or ask an administrator to complete the organization sign-in setup.
