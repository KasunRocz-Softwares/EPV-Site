Load the extension in Brave or Chrome

  1. Extract the ZIP to a folder you will keep, for example Documents\EPV. The browser loads the extension from this folder.
  2. Open chrome://extensions, brave://extensions or edge://extensions.
  3. Turn on Developer mode.
  4. Select Load unpacked and choose the folder that contains manifest.json.
  5. Pin EPV in the toolbar, open the side panel, create a local vault and add a test login.
The extension ID is the same on every install

caijjlabajponibphckpeingakefhfpo. Your administrator uses it to allow the extension on the server and the identity provider.

Connect your organization

Local vaults work right away. For encrypted sync, right-click the EPV toolbar icon, choose Options, and enter the values from your administrator: the API address, identity provider issuer, client ID, audience, and the policy key ID and public key. Choose Save connection and allow access when the browser asks.

IT teams can set and lock these values for everyone with Chrome enterprise policy. The extension reads them from the connection key of its managed storage:

Chrome policy (JSON)
{
  "3rdparty": {
    "extensions": {
      "caijjlabajponibphckpeingakefhfpo": {
        "connection": {
          "apiBaseUrl": "https://vault.example.com",
          "oidcIssuer": "https://login.example.com/realms/epv",
          "oidcClientId": "epv-extension",
          "oidcAudience": "epv-api",
          "policyKeyId": "policy-1",
          "policyPublicKey": "<policy public key>"
        }
      }
    }
  }
}

Deploy it the way you manage Chrome today (Group Policy, an MDM profile or a policy file), and confirm it on one device first. The Options page then shows Managed by your organization.

Verify the download

The SHA-256 checksum of epv-0.1.0-extension-chrome.zip is:

SHA-256
b80e260173dcc864772ff70541500281bd79e9d49597d57bc7daa621a7eb7a00

Compare it with the file you downloaded:

PowerShell
Get-FileHash .\epv-0.1.0-extension-chrome.zip -Algorithm SHA256
macOS / Linux
shasum -a 256 epv-0.1.0-extension-chrome.zip

The same value is in the SHA256SUMS file on the release. This build has no Sigstore signature yet. Only install EPV from this page or the EPV-Site releases.

Update to a new version

  1. Download the new ZIP and extract it over the same folder.
  2. On the extensions page, select the reload button on the EPV card. Your vault and settings stay in place.
Do not remove the extension to update it

Removing EPV deletes the local vault stored in this browser. Keep your recovery code and make sure organization items are synced before removing it.
